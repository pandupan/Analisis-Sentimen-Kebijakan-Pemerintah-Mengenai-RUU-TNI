# Analisis Sentimen Kebijakan Pemerintah Mengenai RUU TNI 📊

> **Dataset dan analisis sentimen opini publik terhadap RUU TNI (Tentara Nasional Indonesia)**

Repositori ini berisi dataset hasil scraping dan pengolahan opini publik dari media sosial/online terkait **Rancangan Undang-Undang Tentara Nasional Indonesia (RUU TNI)**. Data mencakup sentimen positif, negatif, dan netral dari berbagai komentar publik.

---

## 📁 Dataset

| File | Deskripsi |
|------|-----------|
| `Dataset_dummy.xlsx` | Dataset awal (contoh/sample) untuk pengujian |
| `Dataset_Merged.xlsx` | Dataset final yang sudah digabungkan dan dibersihkan |

Dataset berisi data opini publik yang telah melalui proses:
1. **Scraping** — Pengumpulan data dari platform media sosial/berita online
2. **Preprocessing** — Pembersihan teks (stopwords, tokenisasi, normalisasi)
3. **Pelabelan Sentimen** — Klasifikasi sentimen (Positif, Negatif, Netral)

---

## 🛠️ Tools & Metode

- **Microsoft Excel** — Penyimpanan dan pengolahan dataset
- **Python** (pandas, scikit-learn, Sastrawi) — Analisis sentimen & NLP
- **Metode:** Naive Bayes / Support Vector Machine / Lexicon-based
