# 📈 Analisis Sentimen Kebijakan Pemerintah Mengenai RUU TNI

Proyek ini melakukan **analisis sentimen** terhadap opini publik mengenai **Rancangan Undang-Undang (RUU) Tentara Nasional Indonesia (TNI)**. Dataset dikumpulkan dan dianalisis untuk memahami persepsi masyarakat terhadap kebijakan tersebut.

## 📋 Dataset

| File | Deskripsi |
|------|-----------|
| `Dataset_Merged.xlsx` | Dataset hasil penggabungan data mentah dari berbagai sumber |
| `Dataset_dummy.xlsx` | Dataset dummy untuk pengujian awal |

## 🎯 Tujuan Analisis

- Mengidentifikasi sentimen publik (**positif, negatif, netral**) terhadap RUU TNI
- Menganalisis tren opini berdasarkan periode waktu
- Memberikan gambaran umum persepsi masyarakat terhadap kebijakan pemerintah

## 🛠️ Tools yang Digunakan

- **Python** — Untuk pengolahan dan analisis data
- **Pandas / Numpy** — Data processing
- **Excel** — Format penyimpanan dataset
- Metode analisis sentimen berbasis **lexicon** atau **machine learning**
